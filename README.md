# PDF文章抽出 App.

**現在のバージョン：v1.4**

PDFの文章を、コピーしやすいテキストに変換するシンプルなWebアプリです。サーバー側のプログラムは使わないため、GitHub Pagesで公開できます。

## 1. このアプリでできること

- ファイル選択またはドラッグ＆ドロップでPDFを読み込む
- 複数ページの文章をページ順に抽出する
- ページ座標から全幅の見出しと左右2段組みを保守的に判定し、自然な読み順へ並べる
- 不要な空行や、PDFの幅による文章途中の折り返しを自動で整える
- 座標から安全に判断できる上付き・下付き・単純な分数を読みやすくする
- 数式らしい行を文章の改行結合から保護し、明らかな重ね描画を除去する
- ページ区切り（`--- 1ページ目 ---`）を表示／非表示にする
- 抽出結果を直接編集し、ボタンひとつで全文コピーする
- 読み込んだ内容をまとめてクリアする
- PC・タブレット・スマートフォンで利用する

## 2. 使い方

1. `index.html`をブラウザで開きます（後述のGitHub Pagesでの利用がおすすめです）。
2. 点線の枠へPDFをドロップするか、**PDFを選択**を押します。
3. ファイル名を確認して、**文章を抽出**を押します。
4. 必要なら**レイアウトを解析する**、**文章を整形する**、**数式を保護する**、**ページ区切りを表示する**を切り替え、結果を編集します。
5. **全文コピー**を押し、WordやChatGPTなどへ貼り付けます。

> `file://`で直接開くと、ブラウザのセキュリティ設定によりJavaScriptモジュールを読めない場合があります。その場合はGitHub Pages、または `python3 -m http.server 8000` で起動して `http://localhost:8000` を開いてください。初回表示時にはPDF.jsをCDNから取得するため、インターネット接続が必要です。

## 4. PDF.jsは何をしているの？

[PDF.js](https://mozilla.github.io/pdf.js/)は、Mozillaが開発している、ブラウザでPDFを読み取るためのJavaScriptライブラリです。このアプリでは、選択したファイルを `ArrayBuffer`（ブラウザが扱えるデータ）として読み、PDF.jsで1ページずつ文字情報を取得しています。取得した文字をページ順に並べ、テキストエリアへ表示します。

## 5. PDFは外部サーバーへ送信されません

選択したPDFの読み取りと文章抽出は、**すべて利用者のブラウザ内**で行われます。PDFを保存・解析する外部APIやサーバーへのアップロード処理はありません。

PDF.jsのプログラム本体はjsDelivr CDNからダウンロードしますが、選択したPDFがjsDelivrへ送られることはありません。機密情報を扱う場合は、組織のセキュリティルールも確認してください。

## 6. レイアウト解析（v1.4）

**レイアウトを解析する**は初期状態でONです。PDF.jsの各文字列が持つx/y座標、幅、高さを使って行を作り、ページ中央付近に十分広い空白があり、その左右に複数行の文章が重なる高さで存在するときだけ2段組みと判断します。2段組みでは左段を上から下へ読んだ後、右段を上から下へ読みます。

段間を横切るタイトル、注意事項、脚注などは全幅行として扱います。全幅行を境界にページを分けるため、「上部の全幅見出し→左右2段→下部の全幅文章」という順を維持できます。また、大きな縦方向の空白は図や画像の可能性があるため空行を残し、離れた文章を整形機能が無理につながないようにします。

判定が難しいときは従来の上→下・左→右を優先します。大問番号は文字の内容だけを根拠に並べ替えず、座標を主にすることで、本文中の数字を問題番号と誤認する危険を避けています。OFFにするとPDF.jsが返した順番に近い結果へ戻せます。

自動判定は100%正確ではありません。段間が狭い、左右の行数が少ない、表や3段以上、縦書き、文字が図の上に重なる、PDF内の座標自体が不正確、といったページでは判定できないことがあります。その場合はOFFで比較し、結果欄で編集してください。

## 7. 文章の自動整形について

**文章を整形する**は初期状態でONです。連続する空行を1つにまとめ、文章途中の折り返し行をつなぎます。「（趣旨）」のような見出し、「第１」のような条項、番号付き項目、箇条書き、段落を表す空行、ページ区切りは残します。タブ・縦線・大きな空白を含む行は表の可能性があるため、安全を優先してつなぎません。OFFにすると、PDFから取得した行構造に近い文章を確認できます。

バージョンを更新するときは、`script.js`の先頭にある`APP_VERSION`を変更してください。JavaScriptが画面上部とブラウザのタブへ同じ番号を設定します。JavaScriptを読み込む前にも番号が見えるよう、`index.html`内の初期表示2か所も同じ番号に変更します。

PDFには「折り返し」と「段落」を明確に区別する情報がないため、表、縦書き、段組み、番号で始まる文章などは完全に判定できない場合があります。その場合はOFFにするか、抽出結果欄で直接編集してください。

### 数式の保護（v1.3から維持）

**数式を保護する**は初期状態でONです。PDF.jsが返す文字のx/y座標、大きさ、幅を比較し、本文より小さく、直前の文字より上または下にある数字・符号だけをUnicodeの上付き／下付き文字へ変換します。同じ内容・位置・大きさの文字は、わずかな誤差の範囲で一致した場合だけ重ね描画として除去します。

分数は、英数字からなる分子と分母がほぼ同じ横位置で上下に並び、さらに左隣に演算子または括弧がある単純な配置だけを`分子/分母`へ変換します。`=`、三角関数、ギリシャ文字、複数の数字・演算記号など、根拠が複数ある行は数式候補として文章の改行結合から保護します。`π`、`λ`、`Δ`、`α`、`θ`、`√`、`∑`、`∫`、`′`などは削除しません。

ON/OFFは抽出後にも切り替えられます。OFFでは座標を使った補正前の、従来のPDF.jsに近い文字列を確認できます。

#### できることと限界

- `10⁻⁹`、`4.0×10⁻⁴`、`S₁`、`n₂`のような単純な添字は、文字サイズと基準線の差がPDF内に保存されていれば改善できます。
- `t − x/5.0`のような単純な分数は、上下位置と周囲の条件が十分そろった場合だけ変換します。
- PDF.jsは数式の意味、分数線、文字同士の関係を返す数式認識エンジンではありません。複雑な多重分数、根号の範囲、行列、積分範囲、複数行の式、特殊フォントで文字コードが欠けたPDFは完全には復元できません。
- 誤った式を作らないことを優先するため、判定に自信がない配置は元の行・文字順のまま残ります。必要に応じて保護をOFFにして比較してください。

## 8. OCRには現在対応していません

このアプリはPDF内に保存された「文字情報」を抽出します。スキャンした紙や写真だけのPDFには文字情報がないため抽出できず、案内メッセージを表示します。画像から文字を認識するOCRは将来の追加候補です。

## 9. GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作ります。
2. リポジトリ内のファイル一式をリポジトリの一番上へアップロード（またはGitでpush）します。
3. リポジトリの **Settings** → **Pages** を開きます。
4. **Build and deployment** のSourceを **Deploy from a branch** にします。
5. Branchで `main` と `/(root)` を選び、**Save**を押します。
6. 数分後に表示される `https://ユーザー名.github.io/リポジトリ名/` を開きます。

GitHub Pagesは画面のファイルを配信するだけです。PDFの抽出は、公開後も閲覧者のブラウザ内で実行されます。

## 対応範囲と注意点

- テキストの順番はPDF内部の文字配置情報に依存します。複雑な段組み・表・縦書きでは、見た目どおりの順序にならない場合があります。
- PDF.jsをCDNから読み込むため、Content Security Policyを設定する場合はjsDelivrを許可してください。
- 対応ブラウザは、最新版のChrome、Edge、Firefox、Safariを推奨します。
