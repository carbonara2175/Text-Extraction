# PDF文章抽出 App.

PDFの文章を、コピーしやすいテキストに変換するシンプルなWebアプリです。サーバー側のプログラムは使わないため、GitHub Pagesで公開できます。

## 1. このアプリでできること

- ファイル選択またはドラッグ＆ドロップでPDFを読み込む
- 複数ページの文章をページ順に抽出する
- 不要な空行や、PDFの幅による文章途中の折り返しを自動で整える
- ページ区切り（`--- 1ページ目 ---`）を表示／非表示にする
- 抽出結果を直接編集し、ボタンひとつで全文コピーする
- 読み込んだ内容をまとめてクリアする
- PC・タブレット・スマートフォンで利用する

## 2. 使い方

1. `index.html`をブラウザで開きます（後述のGitHub Pagesでの利用がおすすめです）。
2. 点線の枠へPDFをドロップするか、**PDFを選択**を押します。
3. ファイル名を確認して、**文章を抽出**を押します。
4. 必要なら**文章を整形する**、**ページ区切りを表示する**を切り替え、結果を編集します。
5. **全文コピー**を押し、WordやChatGPTなどへ貼り付けます。

> `file://`で直接開くと、ブラウザのセキュリティ設定によりJavaScriptモジュールを読めない場合があります。その場合はGitHub Pages、または `python3 -m http.server 8000` で起動して `http://localhost:8000` を開いてください。初回表示時にはPDF.jsをCDNから取得するため、インターネット接続が必要です。

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の見出し、ボタン、入力欄などの構造 |

## 4. PDF.jsは何をしているの？

[PDF.js](https://mozilla.github.io/pdf.js/)は、Mozillaが開発している、ブラウザでPDFを読み取るためのJavaScriptライブラリです。このアプリでは、選択したファイルを `ArrayBuffer`（ブラウザが扱えるデータ）として読み、PDF.jsで1ページずつ文字情報を取得しています。取得した文字をページ順に並べ、テキストエリアへ表示します。

## 5. PDFは外部サーバーへ送信されません

選択したPDFの読み取りと文章抽出は、**すべて利用者のブラウザ内**で行われます。PDFを保存・解析する外部APIやサーバーへのアップロード処理はありません。

PDF.jsのプログラム本体はjsDelivr CDNからダウンロードしますが、選択したPDFがjsDelivrへ送られることはありません。機密情報を扱う場合は、組織のセキュリティルールも確認してください。

## 6. 文章の自動整形について

**文章を整形する**は初期状態でONです。連続する不要な改行を整理し、文章途中の折り返し行をつなぎます。「（趣旨）」のような見出し、「第１」のような条項、番号付き項目、箇条書き、元からある空行、ページ区切りは残します。OFFにすると、PDFから取得した行構造に近い文章を確認できます。

PDFには「折り返し」と「段落」を明確に区別する情報がないため、表、縦書き、段組み、番号で始まる文章などは完全に判定できない場合があります。その場合はOFFにするか、抽出結果欄で直接編集してください。

## 7. OCRには現在対応していません

v1.0はPDF内に保存された「文字情報」を抽出します。スキャンした紙や写真だけのPDFには文字情報がないため抽出できず、案内メッセージを表示します。画像から文字を認識するOCRは将来の追加候補です。

## 8. GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作ります。
2. この4ファイルをリポジトリの一番上へアップロード（またはGitでpush）します。
3. リポジトリの **Settings** → **Pages** を開きます。
4. **Build and deployment** のSourceを **Deploy from a branch** にします。
5. Branchで `main` と `/(root)` を選び、**Save**を押します。
6. 数分後に表示される `https://ユーザー名.github.io/リポジトリ名/` を開きます。

GitHub Pagesは画面のファイルを配信するだけです。PDFの抽出は、公開後も閲覧者のブラウザ内で実行されます。

## 9. 今後追加できそうな機能

- 縦書きや段組み文書の並び順の改善

- PDF.jsをリポジトリ内に置き、完全オフラインで使える版

## 対応範囲と注意点

- テキストの順番はPDF内部の文字配置情報に依存します。複雑な段組み・表・縦書きでは、見た目どおりの順序にならない場合があります。
- PDF.jsをCDNから読み込むため、Content Security Policyを設定する場合はjsDelivrを許可してください。
- 対応ブラウザは、最新版のChrome、Edge、Firefox、Safariを推奨します。
